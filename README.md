# Task 4: Interactive Business Intelligence Dashboard

## Project Objective
To design and deploy an interactive sales performance dashboard using the Superstore Sales dataset, providing business stakeholders with key macro metrics, regional filtering capabilities, and historical growth trend analysis.

## Key Performance Indicators (KPIs)
* **Total Sales:** $2.29M 
* **Total Profit:** $286.39K
* **Profit Margin:** 12.47%

## Dashboard Features
1. **Executive Summary Cards:** High-level display of global sales, total profit, and profit margins to evaluate overall corporate health at a single glance.
2. **Dynamic Regional Slicing:** An interactive dropdown filter allowing stakeholders to toggle between regions (e.g., isolating East Region metrics: $678,781.24 in Sales and $91,522.78 in Profit).
3. **Time-Series Analysis:** A 4-year historical trend line chart (2014–2017) visually mapping commercial momentum, highlighting a brief consolidation phase in 2015 followed by an aggressive upward growth trajectory through 2017.
